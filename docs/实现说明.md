# 实现说明（开发者向）

本文补充 [README](../README.md) 之外的实现细节，便于后续维护和扩展。

## 1. 分层

```
Views (XAML + code-behind, 只做 UI 编排)
   │  调用
Services (纯文件/文本逻辑，不依赖 UI，可单测)
   │  使用
Models (数据结构 / 列表行 ViewModel)
Helpers (HWND、选择器、对话框、资源管理器)
Localization (Lang + 字典 + Trans 附加属性)
```

设计原则：
- **Service 不弹窗、不读 UI**：所有 UI 交互（确认框、InfoBar）留在 Page；
- **IO 放到线程池**：`await Task.Run(...)` 包住读文件、解析、复制、写文件，避免大站点卡 UI；
- **状态集中**：`AppState.Current`（根目录 / 语言 / 设置）。

## 2. `_config.yml` 解析与写回（`Services/ConfigYamlService.cs`）

### 2.1 为什么不用 YAML 库

需求要求“原有注释、缩进、顺序尽量保持，只改用户改动的项”。通用 YAML 库（YamlDotNet 等）序列化后会丢注释、重排格式，因此这里采用**行级缩进解析**：

- 按行扫描，维护一个“当前祖先栈”；
- 每行记录：`Key`、`Depth`（界面层级）、`Indent`（有效缩进）、`LineIndex`（原文件行号）、`Prefix`（值之前的原始文本，如 `"  title: "`）、`Suffix`（行尾注释）、`QuoteChar`、`RawValue`、`OriginalValue`、`EditingValue`；
- 写回时只需 `行 = Prefix + FormatScalar(EditingValue) + Suffix`，**其它行一个字节都不动**。

### 2.2 关键规则

| 场景 | 处理 |
| --- | --- |
| `key: value` | `FindMappingColon` 找“后面跟空格/行尾”的冒号；URL 的 `http://` 不会被误判 |
| `key:`（空值）+ 更深缩进 | 后出现的子项使其变成分组（只读、可展开） |
| `- item`（块序列纯量） | 作为子项，`Key = "-"`，值可编辑 |
| `- key: value`（块序列映射） | 值从冒号后开始，有效缩进 `indent + 2`；后续同缩进的行视为同级（避免引入“序列项分组”的复杂度） |
| `key: |` / `key: >` | 块标量 → 只读，后续更深缩进行原样跳过 |
| 行尾注释 ` # xxx` | 扫描时跳过引号内与 `[] {}` 内的 `#`，只认“前面是空格”的 `#` |
| 上方整行注释 | 累积到 `pendingComments`；空行会清空（视为“分节标题”，不挂到下一项） |
| 单/双引号 | `QuoteChar` 记录引号类型，写回时保留同类引号 |
| 行内集合 `[a, b]` / `{a: b}` | 作为整体值，写回时不加引号 |

### 2.3 值格式化（写回）

```
原值带引号 → 保留同类引号（' 内部转义为 ''）
否则：空 → 写空；布尔 → 小写裸写；数字 → 裸写；
      行内集合 → 原样；含 : # 特殊首字符或首尾空格 → 单引号包裹；其余裸写
```

### 2.4 写回流程（`Apply`）

1. 收集所有 `IsEditable && IsDirty` 的项；
2. 备份 `_config.yml` → `_config.yml.easyhexo.bak`；
3. 复制原行数组，替换对应行，用原换行符拼接，保留原 BOM 状态写回；
4. 页面重新解析文件（保证界面与磁盘一致）。

## 3. front-matter（`Services/FrontMatterService.cs`）

识别规则与需求一致：
1. 第一行（去 BOM 后）必须是 `---`；
2. 向下找到下一个 `---` / `...`；
3. 中间按 `key: value` 解析出 `title` / `date` / `tags`：
   - `tags: [a, b]` 行内数组；
   - `tags:` 换行后的 `- a` 块序列；
   - `date` 支持 `yyyy-MM-dd HH:mm:ss`、`yyyy-MM-dd`、带时区偏移等；
4. 其它行原样进入 `ExtraLines`，生成时原样写回（例如 `categories`）；
5. 不符合结构 → `HasFrontMatter = false`，整个文件作为正文，由用户填表后再补写。

时间精度：界面用 `DatePicker` + `TimePicker`，没有秒输入框，写回时秒为 `00`（如果原 front-matter 已有秒，会先被读出显示，但发布后未单独编辑秒的话按选择器结果写入）。

## 4. 发布流程（`Services/ArticlePublisher.cs`）

```
UI 校验（标题必填；目标存在则确认覆盖）
   ↓  Task.Run（后台线程）
AssetService.Process      复制本机绝对路径资源 → source\<标题>\ ，改写正文链接
FrontMatterService.Compose  title/date/tags + 原其它字段 + 正文
写入 source\_posts\<标题>.md（已发布文章写回原路径）
若来源是外部 .md 且不是目标文件 → 同时把结果写回该文件开头
   ↓ 回到 UI 线程
刷新文章列表 / 载入下一队列项 / InfoBar 汇报（含复制数量、目标路径）
```

资源处理细节（`AssetService`）：
- 正则 `(?<lead>!?\[[^\]\r\n]*\]\()(?<url>[^)\r\n]+)\)` 匹配 `![alt](url)` / `[text](url)`；
- 只有 `X:\` / `X:/` / `\\server\share` 形式才算本机绝对路径；
- 复制目标文件名冲突时追加 `-2`、`-3`；
- 输出 URL 用 `%20` / `%28` 等转义会破坏 Markdown 的字符，中文保持原样。

## 5. 本地化（`Localization/`）

### 5.1 界面文案

- `Lang`：静态字典（`StringsZhCn` / `StringsEnUs`），`T(key)`、`T(key, args)`；`SetLanguage` 后刷新界面；
- `Trans`：XAML 附加属性 `Text` / `Content` / `Header` / `Placeholder` / `ToolTip`，
  设置时给控件套上当前文案，并用弱引用把控件登记到注册表；
  语言切换时遍历注册表重新套用，因此**不需要重启**；
- 动态文案（InfoBar、统计、路径）在页面代码里用 `Lang.T(...)` 生成；
  设置页切换语言后会调用本页 `ApplyLocalization()` 刷新动态部分；
- 新增文案：两个字典同时加同一个 key（`XAML` 里用 `l:Trans.Xxx="key"`，代码里用 `Lang.T("key")`）。

### 5.2 配置项键名的中文显示（`ConfigKeyTranslator`）

需求：语言为简体中文时，把固定配置项的英文键名翻译成中文**仅用于界面显示**。

- `ConfigRow` 构造时沿 `ConfigEntry.Parent` 链拼出完整键路径（`pretty_urls.trailing_index`）；
- `ConfigKeyTranslator.Translate(path, key)` 先按完整路径查表，再回退英文原名；
  非简体中文时直接返回英文原名；
- 中文名作为主标签，英文原名作为描述行（无注释时）与鼠标悬停提示；
- **写回逻辑完全不受影响**：`ConfigEntry.Key` 始终是英文原名，
  `BuildLine()` 只用 `Prefix + 值 + Suffix`，所以 `_config.yml` 里永远是英文键；
- 新增译名：往 `ConfigKeyTranslator.PathNames` 里加 `"路径" = "中文名"`，
  路径用 `.` 连接，例如 `"deploy.repo" = "仓库地址"`。

## 6. 线程与异常

- 文件读写、解析、复制、发布全部 `Task.Run`，UI 线程只做控件操作；
- 页面按钮在耗时操作期间禁用（发布页显示 `ProgressRing`）；
- 未处理异常写入 `%LOCALAPPDATA%\EasyHexo\logs\easyhexo.log`，并把 `Handled = true` 以免整个应用退出；
- 用户可恢复的错误通过 `InfoBar` 提示（成功/警告/错误三级）。

## 7. 值得扩展的地方

| 需求 | 建议改法 |
| --- | --- |
| 支持新增 / 删除配置项 | `ConfigYamlService` 增加“插入行 / 删除行”操作，`ConfigEntry` 增加行区间信息 |
| 主题 `_config.<theme>.yml` | 复用 `ConfigYamlService`，只需在 `HexoProject` 增加主题配置文件路径 |
| 正文富文本编辑 | 发布页右侧增加 `TextBox` 显示 `FrontMatter.Body`，发布时回填 |
| HTML `<img>` 资源 | `AssetService` 增加 `<img ... src="...">` 正则并复用现有复制逻辑 |
| 秒级时间 | 在时间选择器旁加“秒”数字框，`BuildDate` 使用它 |
| 多语言扩展 | 增加 `StringsXx.cs` 并在 `Lang` 里选择字典 |
