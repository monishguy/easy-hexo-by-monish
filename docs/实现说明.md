# 实现说明（开发者向）

本文补充 [README](../README.md) 之外的实现细节，便于后续维护和扩展。当前对应版本 1.1.0。

## 1. 分层

```
Views (XAML + code-behind, 只做 UI 编排)
   │  调用
Services (纯文件/文本逻辑，不依赖 UI，可单测)
   │  使用
Models (数据结构 / 列表行 ViewModel)
Helpers (HWND、选择器、对话框、资源管理器)
Localization (Lang + 字典 + Trans 附加属性 + 配置键名翻译)
```

设计原则：
- **Service 不弹窗、不读 UI**：所有 UI 交互（确认框、InfoBar）留在 Page；
- **IO 放到线程池**：`await Task.Run(...)` 包住读文件、解析、复制、写文件，避免大站点卡 UI；
- **状态集中**：`AppState.Current`（根目录 / 语言 / 主题 / 资源分组记忆）。

## 2. `_config.yml` 解析与写回（`Services/ConfigYamlService.cs`）

### 2.1 为什么不用 YAML 库

需求要求“原有注释、缩进、顺序尽量保持，只改用户改动的项”。通用 YAML 库序列化后会丢注释、重排格式，因此这里采用**行级缩进解析**：

- 按行扫描，维护“当前祖先栈”；
- 每行记录：`Key`、`Depth`、`Indent`、`LineIndex`、`Prefix`（值之前的原始文本）、`Suffix`（行尾注释）、`QuoteChar`、`RawValue`、`OriginalValue`、`EditingValue`；
- 写回时只需 `行 = Prefix + FormatScalar(EditingValue) + Suffix`，**其它行一个字节都不动**。

关键规则与 1.0 一致（`key:` 空值成组、块序列项、`- key: value` 序列映射、`|`/`>` 只读、行尾注释、引号风格等）。1.1 新增：

- `AppendTopLevelKey(configPath, key, value)`：站点图标没有 `favicon` 项时，在文件末尾追加一行（写前保留换行符 / BOM）。

### 2.2 值格式化（写回）

```
原值带引号 → 保留同类引号（' 内部转义为 ''）
否则：空 → 写空；布尔 → 小写裸写；数字 → 裸写；
      行内集合 → 原样；含 : # 特殊首字符或首尾空格 → 单引号包裹；其余裸写
```

### 2.3 写回流程（`Apply`）

1. 收集所有 `IsEditable && IsDirty` 的项；
2. 备份为 `<配置文件名>.easyhexo.bak`；
3. 复制原行数组，替换对应行，用原换行符拼接，保留原 BOM 写回；
4. 页面重新解析文件（保证界面与磁盘一致）。

## 3. 可视化编辑器（`Services/ConfigEditorMetadata.cs`）

按“完整键路径”（`pretty_urls.trailing_index`）决定控件类型，避免猜错语义：

| Kind | 控件 | 典型键 |
| --- | --- | --- |
| `Bool` | `ToggleSwitch`（写 true/false） | `titlecase`、`highlight.line_number`、`pretty_urls.trailing_index`… |
| `Choice` | `ComboBox`（可编辑，可选列表外值） | `language`、`timezone`、`date_format`、`time_format`、`permalink`、`syntax_highlighter`、`theme`、`deploy.type`… |
| `Number` | `NumberBox` | `per_page`、`index_generator.per_page`、`toc.max_depth`… |
| `Directory` | 文本框 + “浏览”选择文件夹 | `source_dir`、`public_dir`、`tag_dir`… |
| `Text` | 文本框 | 其它项 |

未收录的键如果值恰好是 `true`/`false`，也给开关；其余保持文本，避免误判。

**事件提交规则**（避免模板初始化 / 列表重建时误写）：

- 编辑器事件都先校验 `row.Kind`；
- 下拉框要求真正获得过焦点（`_focusedCombo`），数字框要求有焦点才提交；
- 文本框只在 `Kind` 为 Text/Directory 时提交；
- 这样展开/收起、撤回重建行时不会把 `language`、`per_page` 等清空。

**目录项**：选中的文件夹必须位于 Hexo 根目录内，转换成 `/` 分隔的相对路径（根目录本身写 `.`）。

## 4. 分区排序（`Services/ConfigLayoutService.cs`）

文件本身的顺序不会被修改（写回只替换值所在行），分区只影响界面展示：

`站点信息 → 网址与链接 → 目录 → 写作 → 代码高亮 → 首页与分页 → 分类与标签 → 元信息与时间格式 → 主题与扩展 → 部署 → 其它配置`

- 每个分区是 `ConfigSectionLayout`，分区标题行由 `ConfigRow.CreateSection` 生成，可整段收起；
- 分区内部按定义顺序排序，未在定义里出现的键排在该分区末尾（保持文件顺序）；
- 未识别的顶层键进入“其它配置”。

## 5. 高亮与撤销（`Views/ConfigEditorPage.xaml.cs`）

- `ConfigRow` 实现 `INotifyPropertyChanged`，`RefreshDirtyState()` 刷新 `IsDirty` / 背景 / 边框 / ● 标记；
- 撤销栈 `Stack<UndoStep>`：
  - 文本：`GotFocus` 记录旧值，`LostFocus` 或点“撤回”时算一步；
  - 开关 / 下拉 / 数字 / 目录选择：每次改动立即压栈；
  - “应用配置”或重新载入后清空；
- 撤回后重建可见行（输入内容保存在 `ConfigEntry.EditingValue`，不会丢）。

## 6. 主题与站点图标

### 6.1 主题（`Services/HexoThemeService.cs`）

- 扫描 `<Hexo根目录>/themes/` 的子文件夹，找 `_config.yml` / `_config.yaml`；
- 读取站点配置里的 `theme` 值作为当前主题；
- “一键切换”：把 `theme` 项设为所选主题 → 单行 `Apply` 写回 → 重新载入；其它未应用修改通过 `CapturePendingEdits / RestorePendingEdits` 保留；
- “编辑主题配置”：切到 `themes/<主题>/_config.yml`，使用同一套解析/写回逻辑，但**关闭键名翻译、关闭分区**，按文件缩进展开。

### 6.2 站点图标（`Services/FaviconService.cs`）

- 在当前配置里查找 `favicon`（任意层级、可编辑）；
- 解析：本机绝对路径 / `/x.png`（相对 `source`）/ `x.png`（依次尝试 `source`、根目录）；
- 更换：图片不在 `source` 内时复制到 `source\<文件名>`，再把配置值改为 `/文件名`；
- 配置里没有 `favicon` 时调用 `ConfigYamlService.AppendTopLevelKey` 追加；
- 预览：PNG/JPG/ICO 等用 `BitmapImage`，其它类型显示占位图标。

## 7. front-matter（`Services/FrontMatterService.cs`）

与 1.0 相同：首行 `---`、下一个 `---` 之间的 `title` / `date` / `tags`（行内数组或块序列），其它行原样保留；不符合结构时整个文件作为正文。

## 8. 发布流程（`Services/ArticlePublisher.cs`）

```
UI 校验（标题必填；目标存在则确认覆盖）
   ↓  Task.Run（后台线程）
AssetService.Process(..., selections)  按勾选复制资源并改写正文
FrontMatterService.Compose             title/date/tags + 原其它字段 + 正文
写入 source\_posts\<标题>.md（已发布文章写回原路径）
若来源是外部 .md 且不是目标文件 → 同时把结果写回该文件开头
   ↓ 回到 UI 线程
刷新文章列表 / 从“待发布”移除 / 自动切到下一篇 / InfoBar 汇报
```

`PublishRequest.AssetSelections` 是 `URL -> AssetSelection { Include, SourcePathOverride }`：

- `Include=false`：链接和文件都不动；
- `SourcePathOverride` 非空：用用户为“未识别项”选的本机文件复制；
- 未传 selections（null）时表示全部处理（兼容旧调用）。

## 9. 资源扫描与分组（`Services/AssetService.cs`）

- `Scan(body)`：按顺序匹配 `![alt](url)` / `[text](url)`，只保留“本机绝对路径”（`X:\`、`X:/`、UNC），URL 去重；
- 分类：文件存在且是图片（`![]` 或图片扩展名）→ 图片；文件存在但非图片 → 文件；文件不存在 → **未识别项**；
- 正则与 1.0 相同，仍然不处理 HTML `<img>`。

## 10. 本地化（`Localization/`）

- `Lang`：静态字典（`StringsZhCn` / `StringsEnUs`），`T(key)`；`SetLanguage` 后刷新界面；
- `Trans`：XAML 附加属性 `Text` / `Content` / `Header` / `Placeholder` / `ToolTip`，语言切换时对登记控件重新套用（弱引用，不阻止回收）；
- `ConfigKeyTranslator`：简体中文下按完整键路径翻译固定配置项键名，英文原名作为描述 / ToolTip；写回始终用英文键；
- 新增文案：两个字典同时加同一个 key（`XAML` 用 `l:Trans.Xxx="key"`，代码用 `Lang.T("key")`）；新增配置项译名改 `ConfigKeyTranslator.PathNames`。

## 11. 窗口、主题与自适应（`MainWindow` / `SettingsPage`）

- 最小尺寸：`OverlappedPresenter.PreferredMinimumWidth/Height = 1040/680`；
- 自适应侧栏：`PaneDisplayMode=Auto`，展开阈值 1260、紧凑阈值 800；`PaneOpened/PaneClosed/DisplayModeChanged` 控制 `PaneFooter` 中“当前 Hexo 根目录”的显隐；
- 主题：`AppState.Theme`（`system/light/dark`）→ `ThemeService.ToElementTheme` → 根 Grid `RequestedTheme`；`ContentDialog` 单独套用主题；切换后写入 `settings.json`。

## 12. 待发布文章与草稿（`Views/PublishPage.xaml.cs`）

- `Drafts: ObservableCollection<ImportDraft>`：导入的文件（含 `.txt` 临时文件）插入列表最上方；
- `ImportDraft.State: DraftState`（标题 / 日期 / 标签 / IsModified）：切换文章前 `SaveCurrentEditorState()` 把表单写回当前草稿或已发布文章的会话草稿字典；切回时恢复；
- 已发布文章的修改保存在 `_publishedDrafts`（路径 → 状态），本次会话内有效；
- 发布成功后从列表移除并更新计数，若还有草稿自动切到第一篇。

## 13. 线程与异常

- 文件读写、解析、复制、发布全部 `Task.Run`，UI 线程只做控件操作；
- 页面按钮在耗时操作期间禁用（发布页显示 `ProgressRing`）；
- 未处理异常写入 `%LOCALAPPDATA%\EasyHexo\logs\easyhexo.log`，并 `Handled = true` 以免整个应用退出；
- 用户可恢复的错误通过 `InfoBar` 提示（成功/警告/错误三级）。

## 14. 值得扩展的地方

| 需求 | 建议改法 |
| --- | --- |
| 草稿持久化 | `ImportDraft.State` 序列化到 `%LOCALAPPDATA%\EasyHexo\drafts.json`，启动时恢复 |
| 支持新增 / 删除配置项 | `ConfigYamlService` 增加“插入行 / 删除行”，或把 `AppendTopLevelKey` 扩展成任意位置插入 |
| 更多可视化控件（颜色、路径、多选） | 扩展 `ConfigEditorKind` 与 `ConfigRow` 模板 |
| HTML `<img>` 资源 | `AssetService.Scan` 增加 `<img src>` 正则并复用分组逻辑 |
| 秒级时间 | 时间选择器旁加“秒”输入，`BuildDate` 使用它 |
| 多语言扩展 | 增加 `StringsXx.cs` 并在 `Lang` 里选择字典 |
